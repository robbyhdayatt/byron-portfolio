Masuk menggunakan GitHub Personal Access Token

🔑 Cara membuat GitHub Token ▾
  1. Buka GitHub → Settings → Fine-grained tokens
  2. Token name: byron-cms
  3. Repository access: Only select repositories → pilih byron-portfolio
  4. Permissions → Contents: Read and write (untuk simpan data & upload gambar)
  5. Generate token → copy hasilnya di sini

Token disimpan di sessionStorage browser — hilang otomatis saat tab ditutup.
