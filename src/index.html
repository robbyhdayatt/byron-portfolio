Tentang Saya

Saya seorang Software Developer yang berfokus merancang dan mengembangkan sistem web enterprise berkinerja tinggi. Saat ini berkarier di PT Lautan Teduh Interniaga (Divisi IT), berperan dalam membangun solusi digital operasional seperti sistem manajemen inventori multi-gudang dan ERP jaringan dealer.

Dengan spesialisasi pada arsitektur Full-stack Web (Laravel & React) serta optimasi basis data MySQL, saya mengawal siklus perangkat lunak secara end-to-end — mulai dari perancangan arsitektur hingga deployment dan pemeliharaan server produksi (on-premise perusahaan maupun cloud/hosting).

Didukung latar belakang S1 Ilmu Komputer Universitas Lampung (IPK 3.74/4.00) serta pengalaman memimpin HIMAKOM Unila (142+ anggota aktif) sebagai Ketua Umum, saya menyelaraskan ketajaman teknis dengan komunikasi tangguh dan manajemen proyek terarah.
